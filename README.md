# Gaming & Digital Products Store (Frontend Project)

This repository contains a **frontend-only web application** for an online gaming and digital products store.  
The project is developed using **HTML, CSS, and Vanilla JavaScript** and demonstrates core frontend concepts such as responsive design, multilingual support, and client-side cart management.

---

## 📌 Project Overview

The application simulates an e-commerce platform that offers:

- PC Games
- Digital products (software licenses & subscriptions)
- Custom PC assembly services

Users can browse products, switch languages, add items to a cart, and complete a simulated checkout process.

---

## ✨ Features

### 🌐 Multilingual Support
- Persian (FA) – RTL
- Arabic (AR) – RTL
- English (EN) – LTR
- Dynamic language switching without page reload

### 🛒 Shopping Cart
- Add products to cart
- Real-time cart item counter
- Checkout modal with:
  - Item count
  - Total price calculation
  - Terms & conditions confirmation

### 🎨 User Interface
- Modern dark gaming-themed design
- Responsive layout (desktop & mobile)
- CSS animations and transitions
- Toast notifications for user actions

### 📱 Responsive Design
- Mobile-friendly navigation menu
- Grid-based product layout using CSS Grid

---

## 🧰 Technologies Used

- **HTML5** – Semantic structure
- **CSS3**
  - CSS Variables
  - Flexbox & Grid
  - RTL / LTR support
- **JavaScript (Vanilla)**
  - DOM manipulation
  - Event handling
  - Cart and language logic
